## 太空洗衣機的事實依據
- 國際太空站沒有洗衣機；髒衣服打包放進貨運船，隨船進大氣層燒毀。
- 沒有重力時水不會沉到底，會聚成水球。
- 滾筒洗衣機靠衣服被帶高後摔落拍打來洗；微重力下衣服不會掉落。
- 角動量守恆：機身沒固定時，滾筒轉向一邊，機身會往反方向轉。
- 脫水靠旋轉產生的離心效果，不需要重力（NASA 也有利用旋轉做人工重力的洗碗機概念）。
